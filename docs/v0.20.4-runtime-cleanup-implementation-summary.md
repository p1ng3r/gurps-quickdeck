# v0.20.4 Phase 1 Implementation Summary

The Phase 1 branch preserves the existing UI2 command-desk layout and Foundry Application V1 shell while removing redundant runtime work.

Implemented:

- One startup render instead of an application render plus a second direct overlay render.
- One full overlay view-model build per render; the hidden host template receives an empty data object.
- One native GURPS-compatible pending-damage queue instead of competing shadow state.
- GM-only capture/application of chat damage through `renderChatMessageHTML`.
- Popup-only damage updates instead of unnecessary full-overlay rerenders.
- On-demand loading of developer art-tuner code.
- Installed-version UI labels instead of stale historical build strings.

Deferred to later phases:

- Fragment/region rendering.
- Persistent scrollbar and native-window focus controllers.
- CSS consolidation.
- Release allow-list and unused asset removal.
- Per-book reference bundle loading.
